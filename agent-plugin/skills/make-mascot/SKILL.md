# kisui-terminal のキャラクターを作る

kisui-terminal のリーダー（Cmd+K / Ctrl+Shift+K）の案内を運ぶキャラクターの、`mascot.toml` と、コマごとの画像の指示文を作る。

- 作るのは、(1) 場面ごとのコマの数の案、(2) `mascot.toml`、(3) コマごとの画像の指示文、(4) 置き場所の説明。
- 画像そのものは作らない。使う人が好きな画像生成のサービスで、(3) の指示文を使って作る。特定のサービスや API キーは前提にしない。
- 形式の正は https://github.com/mm1995tk/kisui-terminal/blob/main/docs/mascot.md 。読めるなら先に読み、下の要点と食い違えば文書に従う。この文書は実験的で、形式は予告なく変わる。

## 手順

1. 使う人に聞く（まとめて 1 回で。分からない項目は既定の案を出して確かめる）。
   - 名前（ディレクトリ名になる。英小文字・数字・`-` 程度。`/` と `..` は不可）
   - 見た目（生き物・服・色・絵柄。ドット絵、水彩、フラットなイラスト、など）
   - 一息つく姿（ふぅ、のあとの姿。言葉は絵の中に描く）
   - 休憩の具体（コーヒーを飲む、椅子に座る、など。要らなければ無し）
   - さようならの具体（手を振る、扉から出る、家に帰る、など。1 つ以上を勧める）
   - 押していく場面を作るか（Esc で閉じたときに案内を右へ押して画面の外へ。無ければ運ぶ場面のコマを使う）
   - コマの数（少ないほど画像を作る手間が減る。運ぶは 4 コマ程度、ほかは 1〜4 コマ程度を勧める）
2. 場面ごとのコマの数の案を表にして見せる（場面・コマの数・動きの内容・ファイル名）。
3. `mascot.toml` を作る。
4. コマごとの画像の指示文を作る。
5. 置き場所を説明する。

## 形式の要点

場面は次の 5 つ。いつどの場面になるかは kisui-terminal が決める。`mascot.toml` が決めるのは見た目だけ。

| 表 | 場面 | 必須 | 今の版で動くか |
| --- | --- | --- | --- |
| `[carry]` | 運ぶ。リーダーを開いたとき、案内を押して右へ歩く | はい | 動く |
| `[sigh]` | 一息つく。運び終えたとき | いいえ | 動く |
| `[rest]` と `[[rest.variants]]` | 休憩。具体を 1 つ選んで動く（`[[rest.variants]]` をいくつでも） | いいえ | 動かない場合がある（形式だけ。docs/mascot.md で確かめる） |
| `[[bye.variants]]` | さようなら。閉じたとき、その場で 1 回再生して消える。具体からランダムに 1 つ | いいえ | 動く |
| `[push]` | 押していく。Esc で閉じたとき、案内を右へ押して画面の外まで | いいえ | 動かない場合がある（同上） |

項目:

| 項目 | 意味 | 書かないとき | 使う場面 |
| --- | --- | --- | --- |
| `frames` | コマの画像のパスの並び（キャラクターのディレクトリからの相対パス。`/` で区切ってサブディレクトリも書ける）。1 枚なら静止画 | 場面には必ず書く | 全部 |
| `frame-ms` | 1 コマの時間（ミリ秒。1 以上） | `200` | 全部 |
| `loop` | `true` は最後のあと最初に戻る。`false` は最後のコマで止まる | `true` | 全部（さようならは書いても 1 回だけ） |
| `speed` | 動く速さ（px/秒。0 より大きい） | `90` | 運ぶ・押していく |
| `start-after-ms` | `[rest]` に書く。一息ついてから休憩に入るまでの待ち時間（ミリ秒） | `3000` | 休憩 |

- 休憩とさようならの具体は、具体ごとに `frames`・`frame-ms`・`loop` を書く。
- 一息つく場面は `loop = false` にして、最後のコマで止まる形を勧める。
- 知らない項目は読み飛ばされる。
- パスは、`.` か `..` を区切りの 1 つとして含むパス（`./walk-1.png`・`a/../b.png` など。ファイル名の中のドットは問題ない）・絶対パス・`\` を含むパス、シンボリックリンク、普通のファイルでないものは読まれない。

画像:

- PNG。背景は透明。右向きに描く（左右の反転はされない）。
- 表示の高さは 72px で、幅は縦横比のまま。全部のコマを同じ大きさ（同じ縦横比）にする。運ぶ距離は運ぶ場面の 1 コマ目の縦横比で決まる。
- 1 枚 4 MiB まで。1 つのキャラクターで 256 枚まで。

読めないとき: 運ぶ場面が無い・`mascot.toml` が読めないと、キャラクターは出ず案内だけが出る。ほかの場面は、画像が 1 枚でも読めない・値が使えない（`frame-ms = 0` など）と、その場面が無いものとして扱われる。

## mascot.toml の作り方

- 運ぶ（`[carry]`）は必ず入れる。ほかは聞き取った分だけ入れる。
- ファイル名は場面とコマの番号で付ける（`walk-1.png`、`sigh-1.png`、`bye-wave-1.png` など）。具体が複数ある場面は、具体の名前も入れる。
- 手順 2 の表とファイル名・コマの数が、`frames` と 1 対 1 で合うようにする。
- 例:

```toml
[carry]
frames = ["walk-1.png", "walk-2.png", "walk-3.png", "walk-4.png"]
frame-ms = 200
speed = 90

[sigh]
frames = ["sigh-1.png", "sigh-2.png"]
frame-ms = 300
loop = false

[[bye.variants]]
frames = ["bye-wave-1.png", "bye-wave-2.png", "bye-wave-1.png", "bye-wave-2.png"]
```

## 画像の指示文の作り方

コマごとに 1 つずつ、そのまま画像生成のサービスに貼れる指示文を作る。次の 2 つで構成する。

1. 共通の部分（全コマで一字一句同じにする）。同じキャラクターに見えるようにするため。
   - キャラクターの見た目（生き物・顔・体つき・服・色を具体的に。色は名前か色コードで）
   - 絵柄（線の太さ、塗り方、陰影の有無など。全コマ同じ）
   - 大きさ・構図（全コマ同じ縦横比、キャラクターを枠いっぱいでなくそろえた大きさで、足元の位置をそろえる）
   - 背景は透明（PNG）。影や地面を描かない
   - 右向き（体と顔が右を向く。横から見た姿）
   - 文字や吹き出しは、一息つく場面の「ふぅ」のような、絵の中の言葉だけ
2. コマごとの部分。ファイル名と、そのコマの姿勢・動作（「右足を前に出して歩く 1 コマ目」など）。前後のコマとの違いが分かるように書く。

あわせて、使う人への案内を付ける。

- 最初の 1 コマ（運ぶの 1 コマ目）を作って気に入るまで直し、それを参考画像として渡しながらほかのコマを作ると、同じキャラクターに見えやすい（サービスが参考画像に対応していれば）。
- 背景が透明にならないサービスでは、単色の背景で作ってから、背景を抜く道具で透明にする。
- 全部のコマの画像の大きさ（ピクセル）をそろえる。

## 置き場所の説明

- ディレクトリを `mascot/<名前>/` として、`mascot.toml` と画像を置く。画面を動かすマシン（手元）の、設定のフォルダの下:
  - Linux・macOS: `~/.config/kisui-terminal/mascot/<名前>/`（`$XDG_CONFIG_HOME` が絶対パスならその下。nightly 版は、あれば `kisui-terminal-nightly/`）
  - ssh 先のマシンには置かない。
- 使うキャラクターを、設定ファイル（`config.toml` か `config.local.toml`）の `[gui]` に書く。

```toml
[gui]
mascot = "<名前>"
```

- 窓を開いたときに読む。置いたら、リーダーの `c` → `r`（新しいキャラクターなら `c` → `s` で選ぶ）で読み直す。窓を開き直さなくてよい。
- 画像が足りない・形式が違うときは、kisui-terminal を端末から起動したときの標準エラー出力に `kisui-terminal: mascot: ...` が出る。
