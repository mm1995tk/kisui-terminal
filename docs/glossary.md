# Glossary

The names of the parts of the screen and of the operations. Use these words in conversations, issues, pull requests, commits, documents, and code comments. The base is the English UI. In Japanese documents too, write the English word as it is (for example 「Dialog を開く」「Workspace switcher」), the same way the Japanese UI keeps operation names in English.

- Do not invent a name that is not in this table. When you add a new part, add it here first.
- The "Avoid" column lists other names for the same thing. Do not use them.
- Some code names differ from the names here. Aligning the code names is separate work.
- Where the English UI has no word for a part (for example `PaneGrid`), the component name is listed.

| Term                                   | Means                                                                                                                                                                                                                                                              | Avoid                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| Window                                 | One window of the kisui-terminal app. Only this is a Window; do not call a Dialog a window.                                                                                                                                                                        |                                                     |
| Dialog (`Dialog`)                      | Appears in the center of the screen and blocks other operations until you answer (history, confirmation, add a remote, and so on).                                                                                                                                 | 窓, window, popup                                   |
| Sidebar (`Sidebar`)                    | The left column of the Window.                                                                                                                                                                                                                                     | サイドバー以外の「左の列」                          |
| Machine (`Machine`)                    | Concept. One PC that kisui runs on (this PC, or a PC connected over SSH). A Machine has zero or more Workspaces. Machine operations are in the Machine Dialog (leader `m`), not in the Sidebar.                                                                    |                                                     |
| Workspace (`Workspace`)                | Concept. One working place on a Machine. A Workspace has one or more Panes.                                                                                                                                                                                        |                                                     |
| Workspace section (`WorkspaceSection`) | The part of the Sidebar for one Workspace: the Workspace band and, below it, the tab row. When `shj` is running, the File tree and CHANGES rows follow, and each row scrolls by itself (#284). The Sidebar shows only the section of the focused Workspace (#283). |                                                     |
| Workspace band (`WorkspaceBand`)       | The one-line header of a Workspace: name, branch, and ×, plus the Machine name and a small dot for whether it is connected. Clicking the name opens the Workspace switcher. On the right: "+" (add a tab menu), pencil (rename), ×.                                |                                                     |
| Workspace switcher                     | The Dialog that lists all Workspaces on the left and the tabs of the selected one on the right (leader `w`, Cmd+Shift+W / Ctrl+Shift+W). Moving, creating, renaming, closing, and reordering Workspaces are done here.                                             | ワークスペースの窓, 切り替える窓                    |
| Tab                                    | One entry in the tab row of a Workspace. Kinds: Terminal tab, Browser tab, Database tab.                                                                                                                                                                           |                                                     |
| Terminal tab                           | A Tab that shows Panes (terminal, video, image, PDF).                                                                                                                                                                                                              |                                                     |
| Browser tab (`BrowserTab`)             | One page of the built-in browser (#202; only when enabled in settings). It belongs to a Workspace and is listed under the Workspace band. When selected, every place of the grid becomes that page.                                                                | ブラウザのタブの窓                                  |
| Database tab                           | A Tab that shows a database connection and its results (`docs/database.md`).                                                                                                                                                                                       |                                                     |
| Pane (`Pane`)                          | One section of a Workspace: a terminal, video, image, or PDF.                                                                                                                                                                                                      |                                                     |
| Pane grid (`PaneGrid`)                 | All the Panes of the selected Workspace, laid out in rows and columns. In conversation, say "Pane".                                                                                                                                                                |                                                     |
| Primary pane                           | The Pane where the `shj` connected to kisui runs. When there are two or more Panes, the triangle at the top-left corner (`PrimaryMark`) shows it.                                                                                                                  | プライマリのペイン以外の言い換え                    |
| Pane border (`PaneBorder`)             | The line between two Panes. Drag it to resize.                                                                                                                                                                                                                     | 境界線                                              |
| Focus frame (`FocusFrame`)             | The frame drawn around the focused Pane when there are two or more Panes.                                                                                                                                                                                          |                                                     |
| Pane header (`PaneHeader`)             | The row above a video, image, or PDF Pane (file name and ×).                                                                                                                                                                                                       |                                                     |
| Leader                                 | The key that opens the leader tree (Cmd+K on macOS, Ctrl+Shift+K elsewhere). Most operations are under it.                                                                                                                                                         |                                                     |
| Leader guide (`LeaderMenu`)            | The list of keys you can press next, shown after the Leader.                                                                                                                                                                                                       | リーダーの一覧 (when it means this guide), メニュー |
| Key list                               | The list of every key of the current area, opened with `?`.                                                                                                                                                                                                        | キー一覧, ヘルプ                                    |
| Key footer (`KeyFooter`)               | The line at the bottom of a list or Dialog that shows the operations that work now.                                                                                                                                                                                | 下の段, フッター                                    |
| Shortcut                               | A key a user adds in `[gui.shortcuts]` of the config file to run a Command without the Leader.                                                                                                                                                                     | 近道, ホットキー                                    |
| Command (`CommandId`)                  | A named operation. Keys, the Leader guide, and the Key list are all built from the table of Commands (`app/src/features/commands/commands.ts`).                                                                                                                    | コマンドID (as a name for the operation)            |
| CLI                                    | A subcommand of the `kisui` command.                                                                                                                                                                                                                               |                                                     |
| Notice (`Notice`)                      | A card at the bottom right. It does not block other operations.                                                                                                                                                                                                    | お知らせ以外の「通知」                              |
| Toast (`Toast`)                        | A display that shows for a short time and goes away (zoom level, "copied").                                                                                                                                                                                        |                                                     |
| File tree (`FileTree`)                 | Shown only when the selected Workspace has a Primary pane.                                                                                                                                                                                                         | ファイルツリー以外の「ツリー」                      |
| CHANGES (`Changes`)                    | The list of changed git files (the heading on screen is CHANGES). Shown under the same condition as the File tree.                                                                                                                                                 | 変更一覧                                            |
