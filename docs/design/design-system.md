## 共通の値

部品の CSS は、パレット（`--gh-*`）ではなく `tokens.css` の名前を使う。値を足すときは、すぐ上に説明のコメントを 1 つ書き、`== 見出し ==` のコメントの下に置く（Storybook はそのコメントを説明として出す）。

### 色

| 名前の頭        | 何に使うか                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------- |
| `--color-`      | 地（`bg`・`surface`・`field`）、字（`text`・`text-strong`・`text-muted`・`text-dim`）、縁、主の操作（`accent`）、幕 |
| `--shadow-`     | 後ろを触れたまま重ねるものの影                                                                      |
| `--state-`      | 状態（下の「状態」）                                                                                |
| `--connection-` | 接続の状態（状態の丸）                                                                              |

- 窓の地（`--color-bg`）の上の本文は `--color-text`、カード（`--color-surface`）の中の字は `--color-text-strong`。
- 補いの字（ラベル・説明・状態の文）は `--color-text-muted`。さらに退かせるもの（未接続）だけ `--color-text-dim`。
- `--color-accent` は主の操作の地と、フォーカスの枠にだけ使う。強調したいだけの字には使わない。
- マシンの色（`--machine-color`。`colors.ts` が決め、画面が style で入れる）は、どのマシンのものかを表す。状態の色としては使わない。

### 余白・角

- 余白は `--space-2`・`4`・`6`・`8`・`10`・`12`・`16`・`20`（数は px）から選ぶ。モックの寸法（px）とそのまま対応させるため、名前に数を入れた。
- 角の丸みは `--radius-4`（キーの印）・`6`（小さいアイコンのボタン）・`8`（ボタン・入力欄・行）・`12`（カード）。
- ボタンの高さ（44px）・入力欄の高さ（40px）・窓の幅（560px）は、その部品の CSS に置く（ほかで使わないため）。

### 字

- 画面の字は `--font-ui`（IBM Plex Sans JP。`fonts.ts` で同梱）。コマンド・パス・長いエラー・ターミナルからコピーした字は `--font-mono`（ターミナルと同じ並び）。
- 大きさは役割で選ぶ：`--text-title`（窓の見出し）・`--text-input`（入力欄に打つ字）・`--text-body`（本文。画面の既定）・`--text-caption`（ラベル・補い・等幅）・`--text-label`（一覧の見出し・キーの印）。
- 太さは `--weight-regular`（本文）と `--weight-strong`（見出し・主ボタン・選んでいる行）の 2 つ。`fonts.ts` は 700 も読むが、窓の画面では使っていない。
- 折り返す本文の行の高さは `--leading-text`。

## 状態

状態は意味で決める。部品は、必要な状態だけを持つ（すべての状態を、どの部品にも足さない）。

| 状態     | 意味                                               | 今の見せ方（値）                                                                 | 持つ部品（最初のセット）           |
| -------- | -------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------- |
| 通常     | 押せる・読める                                     | —                                                                                | ボタン                             |
| hover    | 押せるものの上にポインタがある                     | 地を `--state-hover-bg` に（主ボタンは `--color-accent-hover`）。押せないときは変えない | ボタン                             |
| フォーカス | キーの行き先                                     | キーボードで移ったときだけ（`:focus-visible`）枠 `--state-focus-ring`（太さ・間も `--state-focus-ring-*`）。入力欄は内側 1px の枠 | ボタン、窓の枠（focusSelf の窓そのものは枠を出さない） |
| 選択     | 一覧の中で、操作の対象として選んでいる             | 窓の一覧の行：地 `--state-selected-bg`、枠 `--state-selected-outline`、太字        | （後に回した窓の一覧の行）         |
| 無効     | 今は押せない                                       | 濃さ `--state-disabled-opacity`、ポインタは矢印                                  | ボタン                             |
| 処理中   | 押したことを処理している。終わるまで押せない       | 無効と同じ見た目に、`aria-busy`。字を「…しています」に変えるのは呼ぶ側           | ボタン（`busy`）                   |
| 空       | 見せるものが無い                                   | 一覧の代わりに `.card-empty` の文                                                | （後に回した窓の一覧）             |
| 成功     | 済んだ・できた                                     | `--state-success`                                                                | —                                  |
| 警告     | 続けられるが気をつける                             | `--state-warning`                                                                | —                                  |
| 失敗     | できなかった。壊す操作                             | `--state-danger`。ただし窓のエラーの文（`.card-error`）は今は警告の色（未確定）   | —                                  |

同じ見た目に寄せてはいけない、別の意味のもの：

| 意味       | 表すもの                         | 値                                                 |
| ---------- | -------------------------------- | -------------------------------------------------- |
| 所属マシン | どのマシンのワークスペース・タブか | `--machine-color`（マシンごと）                    |
| 接続の状態 | マシンにつながっているか         | `--connection-up`・`--connection-pending`・`--connection-down`（状態の丸） |
| フォーカス | キーの行き先                     | `--state-focus-ring`                               |
| 選択       | 操作の対象として選んでいる行     | `--state-selected-*`                               |

新しく作る所では、この 4 つを別の値で表す。今のサイドバー・ツリー・CHANGES には、フォーカスを接続の色やマシンの色で表す所がある（#306 の「フォーカス・選択・状態の意味」）。どれに寄せるかは未確定なので、変えていない。

## 部品

### ボタン（`Button`）

- **目的**：押して 1 つの操作をする。窓と右下の知らせの下の並び（`.card-actions`）に置く。
- **使う場面**：窓の「決める」「やめる」「閉じる」、確認の「はい・いいえ」、知らせの操作。
- **使わない場面**：サイドバーの帯・タブの行の小さいボタン、ツリーや一覧の行（行そのものを押す）、窓の右上の × などアイコンだけのボタン、ブラウザのツールバー、URL を開くリンク。これらは今の見た目のまま、後で決める。
- **引数**：
  - `variant`：`"primary"`（主の操作）か `"secondary"`（既定）。主ボタンは 1 つの並びに 1 つまでで、右端に置く。やめる・閉じるは `secondary`。
  - `type`：既定は `"button"`。form の中で送るボタンだけ `"submit"`（入力欄の Enter で送れる。`AskpassDialog`）。
  - `disabled`：今は押せない。
  - `busy`：処理中。押せなくし、`aria-busy` を立てる。字を変えるときは呼ぶ側が children を変える（`UpdateBar` の「更新しています…」）。
  - `onClick`、`children`（字は翻訳の表から `T("…")` で引く）。
- **状態**：通常・hover・フォーカス（focus-visible）・無効・処理中。
- **操作とフォーカス**：ふつうの `button` と同じ。Tab で移り、Enter・Space で押す。ボタンはキーを足さない（窓のキーは窓が受ける）。無効・処理中のボタンにはフォーカスが移らない。
- **組み合わせの例**：`components/Button` の `CancelAndPrimary`、下の「組み合わせの例」の窓。

### 窓の枠（`ModalCard`）

- **目的**：真ん中に出して、閉じるまで後ろを触らせない窓の枠。
- **使う場面**：確かめる（閉じる・入れる・許す）、名前を入れる、一覧から選ぶ、キーの一覧。
- **使わない場面**：後ろを触れたまま出しておく知らせ（右下の `.card-notice`。`Notices.tsx`）、すぐ消えるトースト、リーダーの案内、ページ内検索のような帯。
- **引数**：
  - `label`：窓の名前（読み上げ）。見出しと同じ文にする。
  - `onCancel`：Esc（かな漢字変換の Esc は除く）と、`closeOnOutside` のときの外のクリックで呼ぶ。窓は自分では閉じない。閉じるのは、呼んだ側が出すのをやめたとき。
  - `width`：省くと 560px。キーの一覧・マシンの一覧は 640px、ワークスペースを切り替える窓は 880px。狭い画面では左右 16px をあけて縮む。
  - `focusSelf`：ユーザーの操作と関係なく開く窓（確認・ssh の質問・許可）。フォーカスを中のボタンではなく窓そのものに置き、打っていた Enter がボタンを押さないようにする。
  - `closeOnOutside`：打ちかけの入力を失わない窓だけ、外のクリックで閉じる。
- **中の並び**：`.card-body`（見出し `h1.card-title`・本文 `.card-text`・入力欄・`.card-error`）の後に `.card-actions`（`Button` を右寄せ。主ボタンが右端）。狭いとボタンは折り返す。
- **操作とフォーカス**：開くと中の最初の押せるもの（`focusSelf` なら窓そのもの）にフォーカスが移る。Esc で `onCancel`（macOS の全画面が解けないよう、Esc の既定の動きは止める）。閉じると、開く前にフォーカスがあった所へ戻す。決める（Enter）は窓ごとに決める（入力欄の Enter で決める窓は、入力欄が `isComposingKey` で変換の Enter を除く）。
- **組み合わせの例**：下の表。
