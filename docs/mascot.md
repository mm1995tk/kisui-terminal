# キャラクターの形式（実験的）

リーダー（macOS は `Cmd+K`、Linux は `Ctrl+Shift+K`）の案内を、キャラクターが押して運んでくる機能の、画像の置き方と `mascot.toml` の形式。キャラクターの絵を作る人と、キャラクターを配る人は、この文書を見る。

実験的な機能なので、形式は予告なく変わることがある。

## 置き場所と選び方

キャラクターごとにディレクトリを分ける。

```
~/.config/kisui-terminal/          # 設定のフォルダ（nightly は、あれば kisui-terminal-nightly/。$XDG_CONFIG_HOME が絶対パスならその下）
├── config.toml
├── config.local.toml
└── mascot/
    ├── neko/                      # キャラクターの名前のディレクトリ
    │   ├── mascot.toml
    │   ├── walk-1.png
    │   └── ...
    └── inu/
        ├── mascot.toml
        └── frames/
            └── ...
```

使うキャラクターは、設定ファイル（`config.toml` か `config.local.toml`）の `[gui]` に名前で書く。

```toml
[gui]
mascot = "neko"
```

- 書いていなければ、キャラクターは出ない（案内だけが出る）。
- `config.local.toml` に書いた名前が、`config.toml` の名前に勝つ。`config.local.toml` に `mascot = ""` と書くと、`config.toml` で選んでいてもキャラクターを出さない。
- 名前は `mascot/` の中のディレクトリの名前 1 つ（`/` や `..` は使えない）。
- 画面を動かすマシン（手元）の設定のフォルダを読む。ssh 先のマシンには置かない。
- 窓を開いたときに 1 回だけ読む。置き換えたら、窓を開き直す。

## 場面

いつどの場面になるかは kisui-terminal が決める。`mascot.toml` が決めるのは、それぞれの場面の見た目（コマ・コマの時間・くり返し・速さ・休憩までの待ち時間）だけ。

| 表                              | 場面       | いつ                                                                                                                                                                                                                                                                                                                   | 必須   | 今の版で動くか |
| ------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | -------------- |
| `[carry]`                       | 運ぶ       | リーダーを開いたとき。案内を押して、サイドバーの右端から右下の位置まで進む                                                                                                                                                                                                                                             | はい   | 動く           |
| `[sigh]`                        | 一息つく   | 運び終えたとき。「ふぅ」と一息つく姿（言葉は絵の中に描く。吹き出しは出ない）                                                                                                                                                                                                                                           | いいえ | 動く           |
| `[rest]` と `[[rest.variants]]` | 休憩       | 一息つく場面になってから待ち時間（`start-after-ms`。書かなければ 3 秒）が経ったとき。具体（コーヒーを飲む、椅子に座る、など）をランダムに 1 つ選んで動く。くり返さない具体は、最後のコマのあと一息つく場面に戻り、また待ってから選び直す（前と同じ具体になることもある）。くり返す具体は、リーダーを閉じるまでくり返す | いいえ | 動く           |
| `[[bye.variants]]`              | さようなら | リーダーを `Esc` 以外で閉じたとき（リーダーのキーをもう 1 度押す・操作を実行する・一覧に無いキーを押す・窓のフォーカスが外れる）。その場で（移動せずに）1 回再生して消える（手を振る・扉から出る・家に帰る、など）。具体から 1 つをランダムに選ぶ                                                                      | いいえ | 動く           |
| `[push]`                        | 押していく | リーダーを `Esc` で閉じたとき。キャラクターが案内を右へ押して、画面の外まで持っていく。書かなければ、運ぶ場面のコマを使う（速さは運ぶ場面のものを借りず、既定の 90）                                                                                                                                                   | いいえ | 動く           |

`Esc` で閉じたときは、さようならを再生せず、押していく。押していく間の案内は見た目だけで、キーは受けない（リーダーのキーは閉じた時点で効かなくなる）。

## 場面ごとに書く項目

| 項目             | 意味                                                                                                                             | 書かないとき                                   | 使う場面                                        |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | ----------------------------------------------- |
| `frames`         | コマの画像のパスの並び。1 枚なら静止画。パスはキャラクターのディレクトリからの相対パス（`/` で区切ってサブディレクトリも書ける） | 書かないと TOML が読めない（場面には必ず書く） | 全部                                            |
| `frame-ms`       | 1 コマの時間（ミリ秒。1 以上）                                                                                                   | `200`                                          | 全部                                            |
| `loop`           | `true` は最後のコマのあと最初に戻る。`false` は最後のコマで止まる                                                                | `true`                                         | 全部（さようならは、書いても 1 回だけ再生する） |
| `speed`          | 動く速さ（px/秒。0 より大きい数）                                                                                                | `90`                                           | 運ぶ・押していく                                |
| `start-after-ms` | `[rest]` に書く。一息つく場面になってから休憩に入るまでの待ち時間（ミリ秒）                                                      | `3000`                                         | 休憩                                            |

休憩とさようならの具体は、`[[rest.variants]]`・`[[bye.variants]]` をいくつでも並べる。具体ごとに `frames`・`frame-ms`・`loop` を書く。

知らない項目は読み飛ばす（新しい版用に書いた項目があっても読める）。

## 画像

- PNG（背景が透明なもの）。右向きに描く（左右の反転はしない）。
- 表示の高さは 72px。幅は画像の縦横比のまま。運ぶ距離は、運ぶ場面の 1 コマ目の縦横比で決める。全部のコマを同じ大きさにすると、コマを切り替えても位置がずれない。
- 1 枚 4 MiB まで。1 つのキャラクターで使える画像は 256 枚まで（同じファイルを何度書いても 1 枚と数える）。超えた画像を使う場面は、無いものとして扱う。
- 窓を開くときは、ファイルの先頭と大きさだけを確かめる。画像は `mascot:` のスキームで画面に渡す（`data:` の URL にしない）ので、枚数が増えても窓を開くのは重くならない。

### 読まないパス

キャラクターのディレクトリの外を指すパスは読まない。

- `.` か `..` を区切りの 1 つとして含むパス（`./walk-1.png`・`a/../b.png` など。`walk-1.png` のようにファイル名の中にドットがあるのはかまわない）・絶対パス・`\` を含むパス
- 途中か最後がシンボリックリンクのパス（`mascot.toml` 自身がリンクのときも読まない）
- 普通のファイルでないもの（ディレクトリ・FIFO など）

`mascot/` やキャラクターのディレクトリ自身がリンクなのはかまわない（設定のフォルダの決まりと同じ）。

## 無いとき・読めないとき

| こうなったら                                                                                    | こうする                                                     |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 設定でキャラクターを選んでいない・選んだキャラクターのディレクトリが無い                        | キャラクターを出さず、案内だけを今までどおり出す             |
| `mascot.toml` が無い・読めない（TOML の書き方・型の違い）                                       | 同上                                                         |
| 運ぶ場面が無い（読めない画像がある）                                                            | 同上                                                         |
| 場面の画像が 1 枚でも読めない・パスが外を指す・値が使えない（`frame-ms = 0`、`speed = 0` など） | その場面（休憩とさようならは、その具体）が無いものとして扱う |
| 一息つく場面が無い                                                                              | 運ぶ場面の 1 コマ目で止まる                                  |
| 休憩が無い                                                                                      | 一息つく場面のまま                                           |
| さようならが無い                                                                                | その場で消える（運ぶ場面のコマは使わない）                   |
| 押していく場面が無い                                                                            | 運ぶ場面のコマを使う（速さは既定の `90`）                    |

使えない理由は、kisui-terminal を端末から起動したときの標準エラー出力に `kisui-terminal: mascot: ...` の 1 行で出る。

### kisui-terminal が場面を決めるときの決まり

- リーダーのキーは、アニメーションを待たずにすぐ効く。
- 休憩の途中でリーダーを閉じたら、そこで休憩をやめて、閉じたときの動き（`Esc` なら押していく、それ以外ならさようなら）に移る。
- 押していく途中やさようならの途中にリーダーを開き直したら、押していた案内とキャラクターはすぐ消え、サイドバーの右端から新しく運び始める。
- リーダーから実行した操作がダイアログ（`?` のキーの一覧・クリップボードの履歴など）を開いたときは、さようならを再生せず、その場ですぐ消える。
- OS の「動きを減らす」（`prefers-reduced-motion`）が入っているときは、`mascot.toml` に何を書いていてもアニメーションを切る。キャラクターと案内は最初から右下にいて、キャラクターは一息つく場面の 1 コマ目（無ければ運ぶ場面の 1 コマ目）で止まって見える。コマを切り替えない。休憩に入らない。閉じたら（`Esc` でも）押していかず、その場で消える。

## 例

```toml
# ~/.config/kisui-terminal/mascot/neko/mascot.toml

# 運ぶ（必須）。案内を押して歩く 4 コマ
[carry]
frames = ["walk-1.png", "walk-2.png", "walk-3.png", "walk-4.png"]
frame-ms = 200   # 書かなければ 200
speed = 90       # px/秒。書かなければ 90

# 一息つく。最後のコマで止まる
[sigh]
frames = ["sigh-1.png", "sigh-2.png"]
frame-ms = 300
loop = false

# 休憩。5 秒待って、具体を 1 つランダムに選ぶ（くり返さない具体は終わると一息つくに戻る）
[rest]
start-after-ms = 5000
[[rest.variants]]
frames = ["coffee-1.png", "coffee-2.png"]
frame-ms = 500
loop = false    # 終わると一息つくに戻る
[[rest.variants]]
frames = ["chair.png"]
loop = true      # 閉じるまでくり返す（書かなければ true）

# さようなら。1 つをランダムに選んで 1 回再生する
[[bye.variants]]
frames = ["wave-1.png", "wave-2.png", "wave-1.png", "wave-2.png"]
[[bye.variants]]
frames = ["door/1.png", "door/2.png", "door/3.png"]
frame-ms = 250

# 押していく。リーダーを Esc で閉じたとき、案内を右へ押して画面の外まで持っていく。無ければ運ぶ場面のコマを使う（速さは 90）
[push]
frames = ["walk-1.png", "walk-2.png", "walk-3.png", "walk-4.png"]
speed = 240
```

## キャラクターを配る

kisui-terminal はキャラクターを入れる機能を持たない（スクリプトも実行しない）。配る人は、zip を落として `mascot/<名前>/` に広げるスクリプトを配るとよい。スクリプトは自分の名前のディレクトリにだけ書けば、ほかのキャラクターを上書きしない。

```sh
#!/bin/sh
# neko を入れる（例）。設定のフォルダは kisui-terminal と同じ決まりで探す
set -eu
name=neko
url=https://example.com/neko.zip
case "${XDG_CONFIG_HOME:-}" in
  /*) base=$XDG_CONFIG_HOME ;;
  *) base=$HOME/.config ;;
esac
dest=$base/kisui-terminal/mascot/$name
tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT
curl -fsSL "$url" -o "$tmp/$name.zip"
unzip -q "$tmp/$name.zip" -d "$tmp/x"
rm -rf "$dest"
mkdir -p "$dest"
cp -R "$tmp/x/." "$dest/"
echo "入れました: $dest"
echo "設定ファイルの [gui] に mascot = \"$name\" と書いて、窓を開き直してください"
```

zip の中は、`mascot.toml` と画像をそのまま一番上に置く（`mascot.toml` が zip の一番上にあるようにする）。
